# Generating `./datafiles`
Since each user has diffrent inputs, you need to generate it yourself.
I named the files in the format of `day$(D)-$(C).txt`, where `$(D)` is a *two character* day count (meaning day 7 would be `07` and 14 would be `14`), and `$(C)` is a *single character* day-file count (for multiple parts/files) with the counter starting at `1` each day.
